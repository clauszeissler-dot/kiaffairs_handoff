# Codex-Variante

Die aktuelle Version liegt unter [`releases/`](releases/). Nach dem Entpacken
startet der interaktive Installer mit:

```sh
python3 install.py
```

Er fragt einzeln nach Handoff-Schutz, Engineering-, Security- und n8n-Skills,
Rollenprofilen und lokalen Insights. Eine Compaction-Schwelle wird nur nach
expliziter Auswahl konfiguriert.

Nach einer Hook-Installation Codex neu starten und die neue Definition einmal
über `/hooks` prüfen und vertrauen.
